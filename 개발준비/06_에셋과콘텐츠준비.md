## 모델 규격 제안

- 실행은 GLB, Blender `.blend` 원본은 별도 보관. 이름은 `tree-01.glb`처럼 영문 소문자와 하이픈을 사용합니다.
- 런타임 +Y 위, 바닥 XZ, 1단위=1m. 나무/꽃/아바타 원점은 바닥 중심입니다. 스케일 적용 후 실제 로딩에서 축·크기·원점을 확인합니다.
- 개별 GLB 약 2MB 이하, 첫 실행 에셋 합계 약 15MB 이하를 초기 예산으로 제안합니다. 브라우저 다운로드 크기를 측정합니다.
- 저폴리·단순 재질 우선, 처음에는 텍스처 1024px 이하 목표. 예산 수치로 성능 통과를 대신하지 않고 FPS로 조정합니다.
- 꽃은 호흡 완료 때 표시하며 나뭇잎은 독립적으로 이동/삭제할 수 있게 만듭니다.
- 같은 모델·재질을 불필요하게 재로딩하지 않습니다. 사실적인 물·고해상도 HDR은 필수 기능 완료 뒤 검토합니다.

GLB는 관련 모델 데이터를 한 파일로 전달하는 형식입니다. exporter 옵션은 사용하는 Blender 버전의 설명에서 확인합니다. [Blender glTF 설명](https://docs.blender.org/manual/en/4.1/addons/import_export/scene_gltf2.html)

## 후보 출처와 확인 항목

[Kenney](https://kenney.nl/support)는 에셋 페이지 자료를 CC0로 안내하고, [Poly Haven](https://polyhaven.com/license)은 에셋과 웹사이트/API 조건을 구분합니다. 개별 파일의 제작자·페이지·정확한 라이선스를 기록하고 필요한 고지를 보관합니다. 사이트 이름만으로 모든 파일을 검토한 것으로 표현하지 않습니다.

선택한 파일의 URL·제작자·라이선스·용량·수정 내용·확인일을 에셋목록에 채웁니다. 다른 교육용 파일은 웹 시연·제출·재배포 조건도 확인합니다. 코드 라이브러리의 고지는 모델 출처와 별도로 유지합니다.

## 감정 추천 초안

| ID | 표시 | 추천 | 안내 |
|---|---|---|---|
| anxiety | 불안하고 긴장돼요 | 호흡의 숲 | 잠시 멈춰 빛의 움직임을 바라보며 쉬어보세요. |
| overloaded | 생각이 많고 답답해요 | 비움의 호수 | 고민을 하나 골라 나뭇잎에 담아 흘려보세요. |
| lonely | 외롭고 연결이 필요해요 | 연결의 광장 | 가벼운 응원 한마디를 나누어보세요. |
| tired | 지치고 쉬고 싶어요 | 호흡의 숲 | 천천히 쉬면서 나에게 편한 속도를 찾아보세요. |
| calm | 편안하게 둘러보고 싶어요 | 자유 선택 | 마음이 가는 공간에서 잠시 머물러보세요. |

고민 범주는 `study` 학업, `career` 진로·취업, `relationships` 대인관계, `financial` 경제적 부담, `other` 그 밖의 고민, `prefer_not_to_say` 선택하지 않고 흘려보내기입니다. 마지막 항목도 자유 입력을 열지 않습니다. 전체 활동 건너뛰기는 별도 버튼입니다.

작성 초안이며 팀 검수 완료 실적은 아닙니다. 진단·답 강요·개선 보장·비교와 평가 표현이 없는지 확인합니다. UI·서버는 ID만 사용하고 임의 문구를 받지 않습니다. 시스템 카드에는 ‘시스템 응원’, 실제 수신 카드에는 ‘다른 방문자의 응원’을 표시합니다.

## 안내와 음향

시작: ‘마음정원은 잠시 쉬고 나의 상태를 돌아보는 공간이에요. 모든 활동은 건너뛰거나 종료할 수 있어요.’

호흡: ‘빛을 바라보며 편한 속도로 쉬어보세요. 속도를 맞추기 어렵다면 나의 호흡대로 쉬어도 괜찮아요.’

결과: ‘체험 전후 내가 선택한 상태예요. 감정이 그대로여도 괜찮아요.’

음향은 처음에 꺼두고 사용자가 허용한 뒤 낮은 음량으로 재생합니다. 다른 구역 소리가 겹치지 않도록 정리합니다. 음원이 없거나 로딩이 실패해도 활동이 중단되지 않습니다. 외부 지원정보는 실제 공식 URL을 확인했을 때만 추가합니다.
