# 테스트와 사용자 평가 준비

검증 방법과 빈 양식입니다. 테스트 합격 결과나 사용자 응답을 작성하지 않았습니다.

## 내부 검증

[테스트케이스.csv](테스트케이스.csv)의 28개 사례는 정상 흐름, 중단, 누락 입력, 연결 실패, 잘못된 통신 입력을 포함합니다. 구현 후 검토자가 날짜·결과·재현기록을 적습니다. FR/NFR ID로 명세와 연결합니다.

오류는 [버그기록_빈양식.csv](버그기록_빈양식.csv)에 기록합니다. 재현절차·기대/실제결과·장치·담당·기한을 적습니다. 실행 차단·개인 상태 노출·응원 오작동·반복 활동 중단은 평가 전에 우선 수정합니다.

### 공동 접속 확인

1. 독립 브라우저 두 개로 입장하고 두 화면의 실제 임시 아바타 목록을 확인합니다.
2. 두 아바타를 광장으로 이동합니다. A의 C01 전송 후 B에 실제 수신 카드가 표시되는지 확인합니다.
3. A의 호흡 완료 후 A의 안개/꽃만 바뀌는지 확인합니다.
4. B 종료 후 아바타 제거와 A의 ‘시스템 응원’을 확인합니다.
5. 서버 중단 중 개인 활동·체크아웃을 이용합니다. 재접속 후 과거 응원 자동 전송과 유령 아바타가 없는지 확인합니다.
6. 3명·5명과 여섯 번째 입장 거절/개인 체험을 확인합니다.
7. 다른 실제 PC와 최종 시연 장소에서도 반복합니다. 두 탭만으로 장소 연결 시험을 완료 처리하지 않습니다.

시연 영상에는 두 개 이상의 실제 화면과 실제 수신 장면을 담습니다. ack나 가짜 아바타만으로 송수신을 판단하지 않습니다.

### 성능 확인

기준 PC의 CPU/GPU/RAM·브라우저 버전, 1366×768 viewport, devicePixelRatio·품질·전원을 기록합니다. 로딩 준비시간을 제외하고 같은 카메라/동선으로 구역별 30초 측정합니다. 호흡 연출과 5명 접속 상황도 확인합니다.

평균 FPS는 `렌더 프레임 수 / 실제 측정 초`, 각 구역 30FPS 이상 목표입니다. 낮은 구역과 끊김도 기록합니다. 모델·그림자·텍스처·픽셀 비율 조정 후 같은 조건에서 다시 측정합니다.

## 사용자 평가 운영안

대학생 15~20명의 자발적 참여를 목표로 합니다. 체험 5~10분과 별도 설문 시간을 안내합니다. 실제 인원·중단·미응답을 기록합니다. 사전/사후 응답은 `E01` 같은 평가용 코드로 연결하되 소켓 ID와 연결하지 않습니다.

이름·학번·연락처·진단 정보는 받지 않습니다. 동의·중단 안내, 보관 위치·접근 담당·삭제 날짜를 정한 뒤 모집합니다. 학교/수업의 절차가 있다면 담당자와 확인합니다. 결과는 사용성과 체험 직후 주관적 반응으로 해석합니다.

### 참여 안내 초안

> 마음정원은 대학생을 위한 짧은 가상 휴식 콘텐츠입니다. 약 5~10분 체험 후 사용 경험을 묻습니다. 참여는 자발적이며 활동이나 설문을 건너뛰고 언제든 중단할 수 있습니다. 이름, 학번, 연락처는 받지 않습니다. 응답은 프로젝트의 사용성 평가와 수업 보고에 활용합니다. 개인을 식별하는 내용을 자유 의견에 쓰지 않도록 부탁드립니다.

배포 전 보관 담당·이용 범위·삭제 날짜·문의 방법을 추가합니다. 문의 연락처는 응답항목과 분리합니다. 보관 조건이 비어 있는 초안을 바로 배포하지 않습니다.

### 설문 문항

사전/사후 두 문항의 표현·방향·척도를 동일하게 유지합니다.

| 단계 | 질문 | 응답 |
|---|---|---|
| 사전/사후 | 지금 긴장되는 정도는 어느 정도인가요? | 1 전혀 긴장되지 않음 ~ 5 매우 긴장됨 |
| 사전/사후 | 지금 편안한 정도는 어느 정도인가요? | 1 전혀 편안하지 않음 ~ 5 매우 편안함 |
| 사후 | 조작과 화면 안내를 이해하기 쉬웠나요? | 1 전혀 그렇지 않음 ~ 5 매우 그렇다 |
| 사후 | 공간과 활동에 집중해서 참여할 수 있었나요? | 동일한 1~5 척도 |
| 사후 | 전체 체험에 만족하나요? | 동일한 1~5 척도 |
| 사후 | 다시 이용해보고 싶나요? | 동일한 1~5 척도 |
| 사후 | 가장 편하게 느낀 공간은 어디인가요? | 숲/호수/광장/없음/응답 안 함 |
| 사후 | 불편한 점이나 개선할 점이 있나요? | 자발적 의견, 개인 식별 내용 제외 |

응답 안 함을 허용하고 빈 값을 0점으로 처리하지 않습니다. 임상 선별검사는 추가하지 않습니다.

### 관찰 항목

동의, 체험 시간, 세 구역 방문, 활동별 완료/건너뜀, 체크아웃 도달, 도움 요청, 오류, 사전/사후 응답·사후 평가값을 [평가기록_빈양식.csv](평가기록_빈양식.csv)에 적습니다. 중단 이후 값을 채워 넣지 않습니다. CSV는 헤더만 있는 빈 양식입니다.

## 지표 계산

- 주요 동선 완료율: `전체 동선 도달 인원 / 동의 후 체험 시작 인원 × 100`, 목표 80% 이상. 중단도 분모에 포함하고 이유를 구분합니다.
- 동선 완료는 체크인(응답 건너뛰기 포함), 세 구역 방문, 각 활동 완료 또는 명시적 건너뛰기, 체크아웃 도달입니다. 단순 종료와 구분하고 실제 활동 완료율도 별도 보고합니다.
- 편의성·만족도: 각 문항의 유효 응답 평균과 응답 수를 기록. 각각 평균 4.0/5.0 목표입니다.
- 긴장감 감소값: `사전 - 사후`. 편안함 증가값: `사후 - 사전`. 두 값이 있는 코드만 짝지어 계산하고 제외 수를 기록합니다.
- 체험 시간과 5~10분 내 완료 비율을 보고하고 자율 휴식·중단 등 원인을 함께 기록합니다.
- 자유 의견은 조작·동선·문구·음향·성능 등 문제별로 묶어 개선 순위를 정합니다.

비교군 없는 소규모 평가를 치료 효과나 장기적 개선의 입증으로 표현하지 않습니다. 값이 좋아지지 않은 참가자도 포함합니다.
