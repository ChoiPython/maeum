# 개발 준비자료 검증 기록

검증일: 2026.10.12 / Windows PowerShell / 작업 폴더의 준비자료 대상

## 실행한 검사

| 검사 | 실제 결과 |
|---|---|
| `node 개발준비/준비자료검증.mjs` | 준비자료의 정합성 조건 통과 |
| JSON 파싱과 콘텐츠 ID | 감정 5개·고민 6개·응원 6개, 계약 타입의 ID와 일치 |
| 공간·추천·시간 설정 | 유효한 추천 구역, 겹치지 않는 구역, 60초 호흡·접속 5명 설정 확인 |
| 작업/테스트 추적성 | 14개 기능·6개 비기능 요구가 작업과 테스트에 연결됨 |
| CSV | 작업 30개·에셋 12개·테스트 28개, 평가/버그 양식 각 1개. 행과 열 파싱 확인 |
| 선행작업·담당·일정 | 참조 누락/순환 없음, 별도 검토자, 2026.12.07 이내 기한 |
| 문서 링크 | 연결된 로컬 파일 존재 확인 |
| TypeScript 계약 | TypeScript 5.9.3 strict·noEmit, ES2022·NodeNext 검사 exit code 0 |

공통 타입 검사 재현 명령:

```powershell
npm.cmd exec --yes --package=typescript@5.9.3 -- tsc --strict --noEmit --target ES2022 --module NodeNext --moduleResolution NodeNext '개발준비/공통설정/contracts.ts'
```

컴파일러는 검증용으로 npm 캐시에서 실행했습니다. 마음정원 실행 패키지나 게임 코드, 서버의 구현 검사로 해석하지 않습니다. 검증 스크립트는 외부 웹 URL의 접근 가능성을 자동 검사하지 않습니다.

## 실제 개발에서 확인할 항목

Vite·Three.js·Socket.IO의 설치와 실행 잠금 파일, WebGL/GLB 실제 표시, 이동·활동·응원 기능, 서버 검증과 연결 복구, Chrome·Edge·FPS, 사용자 평가 결과는 아직 검사할 구현물이 없습니다. 첫 개발 작업과 테스트 계획에 포함했습니다.

Blender는 PATH와 일반 설치 경로에서 발견되지 않았습니다. 다른 위치 설치 여부 또는 설치가 필요합니다. 팀 저장소 접근·가능시간·실제 시연 네트워크·외부 서버/비용·설문 보관 조건은 결정사항으로 남겼습니다.

기존 계획서, PDF, 발표자료는 변경하지 않았습니다. 개발 작업 30개는 미착수, 테스트 28개는 미실행, 에셋은 미선정/제작 전 상태입니다. 평가와 버그 기록에는 가상 결과를 채우지 않았습니다.
