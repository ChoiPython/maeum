## 2. 개발 기준

- Three.js + TypeScript + Vite, HTML·CSS UI, Blender GLB 모델, Node.js + Socket.IO.
- PC Chrome·Edge, 하나의 정원과 호흡의 숲·비움의 호수·연결의 광장.
- 안내를 따라 5~10분 체험, 60초 호흡 안내, 최대 5명 공동 접속.
- 감정·고민·전후 응답·개인 안개/꽃은 브라우저 메모리에 유지합니다.
- 서버는 임시 접속자와 위치, 허용된 응원 ID를 처리합니다.
- 계정·DB·자유 채팅·AI 감정 분석·모바일 전용 조작·VR은 후속 범위입니다.

위 큰 방향은 교수 피드백 반영 계획서를 따릅니다. **감정 선택지, 문구, 좌표, 속도, 통신 주기, 에셋 용량 등 새 세부값은 개발을 시작하기 위한 제안값입니다.** 결정사항 표에서 팀이 검토한 뒤 변경할 수 있습니다. 학생의 학번·연락처·이메일은 실행 설정이나 평가 양식에 복사하지 않았습니다.

## 4. 첫 착수 순서

1. 팀 회의에서 역할과 공통 규칙을 검토합니다. 기본 작업 배정은 최주영(통합·서버), 장재혁(공간·환경), 심가현(UI·평가)입니다.
2. `04_개발환경과협업.md`의 명령으로 `mind-garden` 프로젝트를 만듭니다. 세 명이 같은 저장소·Node 버전·잠금 파일을 사용합니다.
3. 도형으로 구성한 정원과 감정 UI부터 연결합니다. 장식 모델을 기다리지 않습니다.
4. 10월 15일까지 두 브라우저 접속 및 테스트 장소의 연결 가능 여부를 먼저 확인합니다.
5. 10월 19일까지 3구역을 이동하고 모든 감정 선택의 추천이 작동하는 상태를 만듭니다.

기존 10월 6~12일 개발 샘플의 완료 여부는 확인되지 않았습니다. 이번 자료는 그 작업이 끝났다고 가정하지 않고 첫 주에 환경 구성과 최소 샘플 확인을 포함합니다.
