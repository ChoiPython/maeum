# 마음정원 요구사항 명세서

버전 0.1 / 2026.10.12 / 기준 문서: 교수 피드백 반영 고도화계획서

## 제품과 범위

대학생이 PC 브라우저의 작은 자연공간에서 현재 감정을 선택하고, 짧은 활동을 경험하고, 자신의 체험 전후 상태를 확인합니다. 개발 목표는 이용 가능한 체험과 소규모 공동 접속 시연입니다. 사용자에게 정서 개선을 보장하거나 감정을 평가하는 결과를 표시하지 않습니다.

| 이번 학기 필수 | 후속 개발 |
|---|---|
| 입구, 연결된 3구역, 아바타 평면 이동, 마우스 선택 | 대형 월드, 점프·충돌·정교한 물리 |
| 감정 선택·수동 규칙 추천 | 얼굴·음성·AI 감정 분석 |
| 호흡 안내·안개/꽃 변화, 고민 범주·나뭇잎 연출 | 센서, 자유 입력 고민, 사실적인 물 시뮬레이션 |
| 3~5명 접속, 6개 선택형 응원 | 자유 채팅·음성·회원가입·DB·수집/거래 |
| 체크아웃, 임시 마음 씨앗, 음소거·건너뛰기·종료 | 영구 기록·모바일 전용 조작·VR |

처음에는 혼자 사용하는 기능을 제작합니다. 최종 결과에는 두 명 이상의 실제 독립 접속에서 응원이 전달되는 장면이 필요합니다. 단일 사용자 완성본만으로 공동 접속 요구사항이 충족되었다고 기록하지 않습니다.

## 기능과 완료 기준

P0는 최종 시연에 필요한 기능이며, 아래 순서는 구현 우선순위입니다. 요구 ID를 작업표와 테스트표에 함께 사용합니다.

| ID | 기능 | 구현 조건과 완료 기준 | 주 담당 / 검토 |
|---|---|---|---|
| FR-01 | 시작 안내 | 목적·조작·권장 소요시간 안내. ‘시작’ 이후에만 오디오를 허용하며 종료 가능 | 심가현 / 장재혁 |
| FR-02 | 개인 체크인 | 감정 5종, 긴장감·편안함 1~5점 선택. 응답 건너뛰기 가능. 선택을 바꿀 수 있음 | 심가현 / 장재혁 |
| FR-03 | 활동 추천 | anxiety/tired는 숲, overloaded는 호수, lonely는 광장, calm은 자유 선택. 모든 선택에 안내 표시. 추천을 따를 의무 없음 | 심가현 / 장재혁 |
| FR-04 | 정원 이동 | 연결된 세 구역, WASD/방향키 평면 이동, 고정 각도 추적 카메라, 구역 표지. UI에 포커스가 있으면 이동 키 처리 중지 | 최주영 / 심가현 |
| FR-05 | 호흡 안내 | 60초의 실제 활성 시간만 누적. 시작·일시정지·재개·다시 시작·완료·건너뛰기 구분. 탭 숨김 시 정지, 복귀 후 명시적 재개 | 심가현 / 장재혁 |
| FR-06 | 개인 환경 반응 | 호흡 진행률에 따라 안개가 옅어짐. 완료 후 꽃 표시. 다른 접속자의 안개/꽃에 영향 없음. 재시작 시 해당 연출 초기화 | 장재혁 / 최주영 |
| FR-07 | 고민 내려놓기 | 6개 범주와 건너뛰기. 선택 후 나뭇잎 클릭 또는 같은 기능의 UI 버튼으로 흘려보냄. 약 6초 연출 중 중복 생성 금지 | 장재혁 / 최주영 |
| FR-08 | 공동 접속 | 최대 5명의 임시 아바타 표시, 연결·재접속·퇴장·정원 만원 상태 처리. 재접속 시 서버 상태를 새로 받음 | 최주영 / 심가현 |
| FR-09 | 선택형 응원 | 6개 ID만 허용. 광장 안의 다른 접속자에게 전송. 서버 간격 제한, 실패·대기 안내, 실제 두 화면 송수신 검증 | 최주영 / 심가현 |
| FR-10 | 혼자/연결 끊김 처리 | 혼자일 때 ‘시스템 응원’이라고 표시. 통신 실패 시 개인 활동 이용 가능. 오프라인 응원을 쌓았다가 나중에 자동 전송하지 않음 | 최주영 / 심가현 |
| FR-11 | 체크아웃과 결과 | 현재 긴장감·편안함 선택. 전후 값을 정확히 표시하고 미응답은 ‘응답 없음’. 개선/악화 등 성공·실패 판정 없음 | 심가현 / 장재혁 |
| FR-12 | 씨앗·새 체험 | 결과 화면에 방문 기념 아이콘. 활동을 건너뛰어도 수여. 새 체험은 모든 개인 응답과 활동 상태 초기화 | 심가현 / 장재혁 |
| FR-13 | 이용 제어 | 모든 활동에 건너뛰기·중단·종료. 음소거·음량 제어. 버튼 키보드 포커스, 텍스트로 상태 안내 | 심가현 / 장재혁 |
| FR-14 | 데이터 최소 처리 | 감정·고민·평가값·개인 연출은 소켓 payload·URL·브라우저 영구 저장소·서버 앱 로그에 포함하지 않음 | 최주영 / 심가현 |

FR-07의 6초, FR-03의 세부 매핑과 FR-09의 문구는 새 제안값이며 공통 설정에서 관리합니다.

## 비기능 요구사항

| ID | 요구사항 | 검증 조건 |
|---|---|---|
| NFR-01 | 브라우저 | 실제 Chrome·Edge에서 각각 전체 체험. 버전과 테스트 날짜 기록 |
| NFR-02 | 성능 | 팀 기준 PC, 1366×768, 같은 품질 설정에서 구역별 30초 측정. 각각 평균 30FPS 이상 목표 |
| NFR-03 | 재현 가능 실행 | 같은 Node 버전과 잠금 파일을 사용해 다른 팀원 PC에서 설치·빌드·접속 |
| NFR-04 | 접근성·편안함 | UI 키보드 조작, 선택을 색상 외 텍스트로 표시, 음소거, 이동 제약 안내, 깜빡임·급격한 카메라 전환 최소화 |
| NFR-05 | 장애 처리 | WebGL 불가·모델/음원 로딩 실패·서버 중단 상태에 실행 가능한 안내. 기본 도형과 무음 사용 가능 |
| NFR-06 | 외부 콘텐츠 | 사용하는 개별 모델·음원·아이콘의 출처와 이용조건을 기록. 확인 안 된 파일은 최종 빌드에서 제외 |

성능과 만족도 수치는 목표입니다. 현재 달성 여부는 미검증입니다. 초기 에셋 예산은 첫 다운로드 약 15MB 이하, 개별 GLB 약 2MB 이하를 제안하며 FPS 결과에 따라 조정합니다.

## 완료의 정의

기능 담당자는 정상 흐름과 중단/실패 흐름을 구현하고, 지정된 검토자가 관련 테스트케이스를 확인합니다. TypeScript 검사와 빌드가 통과해야 하며 브라우저 콘솔에 재현 가능한 오류가 없어야 합니다. 실제 결과·장치·버전을 기록하고 코드, 실행 안내, 변경된 설정을 함께 통합합니다.

주요 체험 동선은 시작, 체크인(건너뛰기 포함), 세 구역 방문, 각 활동 완료 또는 명시적 건너뛰기, 체크아웃 화면 도달입니다. 활동별 완료율은 별도로 계산합니다. 자발적인 종료와 평가 중단도 별도로 기록하며 동선을 강제로 진행시키지 않습니다.
