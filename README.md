# 마음정원 (Mind Garden)

대학생을 위한 감정 반응형 웹 3D 휴식 공간입니다. 하나의 정원 안에서 호흡의 숲, 비움의 호수, 연결의 광장을 경험하는 PC 브라우저 콘텐츠를 개발합니다.

## 자료

- [개발 준비자료](개발준비/README.md): 요구사항·화면 흐름·기술 계약·작업표·테스트·평가 양식
- [기획자료](기획자료/): 학번을 제거한 공개용 계획서 사본
- [진행 기록](docs/진행기록.md): 구현 단계와 실제 검증 결과

## 개발 단계

1. 공통 실행 환경, 3구역 정원·아바타 이동, 감정 체크인·추천, 소규모 접속 기반
2. 60초 호흡 안내와 개인 안개·꽃 연출
3. 고민 범주 선택과 나뭇잎 흘려보내기
4. 선택형 응원 전달과 연결 예외 처리
5. 체크아웃·음향·접근성·성능·사용자 평가와 개선

Three.js·TypeScript·Vite, Node.js·Socket.IO를 사용합니다. 감정·고민·전후 응답은 브라우저 메모리에서 처리하며 서버에는 임시 아바타 위치와 허용된 응원 ID만 전달하도록 개발합니다.

전문적인 진단·치료를 제공하지 않으며 활동은 선택적으로 참여합니다. 개발·평가 목표와 실제 검증 기록을 구분합니다.
